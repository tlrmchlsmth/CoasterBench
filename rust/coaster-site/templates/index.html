Each round a model submits a track program. OpenRCT2 builds it, runs a test train, and returns ratings and a screenshot; the reported score is excitement.
flowchart LR M["model
track program"] --> B["build + validate"] B --> T["test train"] T --> R["ratings + screenshot"] R --> M B -. rejected piece .-> M

Pieces are placed through the same validated action path the game uses for player input, so an impossible curve or an open circuit fails as it would in-game. Intensity above 10 suppresses excitement, a crash disqualifies the ride, and designs close to the stock library scale toward zero. Ratings come from the game, not from a model.
